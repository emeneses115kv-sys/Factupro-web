# Reglas e Instrucciones Persistentes del Proyecto

- **Diagnóstico y Corrección Automática de Errores**: Ante cualquier código de error, crash o registro de falla enviado, analizar de inmediato la causa raíz, aplicar las correcciones pertinentes en el código y verificar la compilación hasta garantizar el correcto funcionamiento de la aplicación en el emulador.
- **Optimización de Dependencias**: No instalar ni mantener dependencias o paquetes innecesarios. Mantener el proyecto limpio, ligero y optimizado para reducir el tamaño del APK y los tiempos de compilación.
- **Calidad y Verificación**: Compilar y validar continuamente el código asegurando que no queden errores de sintaxis, advertencias críticas o dependencias faltantes.
